# obman — MVP 0.4

Небольшое Windows-приложение для локальной диагностики сетевого соединения с Claude.

## Что уже работает

- Кнопка открытия [Net.Coffee Claude IP Check](https://ip.net.coffee/claude) в браузере.
- Проверка DNS и HTTPS-доступности `claude.ai` и `www.anthropic.com`.
- Отображение базового, объяснимого индекса успешности этих четырёх проверок.
- По запросу — просмотр процессов, связанных с Claude, v2rayN и sing-box.
- Локальный журнал событий SQLite и экспорт журнала в JSON/TXT.
- Русскоязычный интерфейс на Tkinter, без сторонних Python-зависимостей.
- Вкладка «Проверка IP и сети»: ручной ввод IP, региона, Trust Score и примечаний Net.Coffee.
- История этих результатов с отметкой изменения IP и региона между последними записями.
- Отдельные пояснения HTTP 401/403/429/5xx, ошибок DNS/TLS и отказов прокси CONNECT 403/407.
- Кнопка «Среда / прокси»: показывает наличие настроек без адресов, паролей и токенов.
- Вкладка «История и отчёт»: последние 200 запусков, результаты выбранной проверки и сравнение статусов с предыдущей.
- Просмотр единого JSON-отчёта перед сохранением для передачи в поддержку вручную.

## История и диагностический отчёт

После проверки откройте «История и отчёт», выберите запись и нажмите
«Просмотреть отчёт…». Кнопка сохранения записывает ровно показанный JSON.
Приложение само никуда отчёт не отправляет.

В отчёт входят время проверки, индекс соединения, статусы DNS/HTTPS, время ответа,
изменения относительно предыдущей записи и наличие настроек среды **на момент проверки**.
Для старых записей без снимка среды указано `null`. Существующая база обновляется
автоматически с сохранением прежних событий, результатов и записей Net.Coffee.

В этот отчёт не включаются IP из DNS, адреса и пароли прокси, свободный текст ошибок,
процессы, журнал событий и записи Net.Coffee. Прежняя кнопка «Экспорт журнала…»
остаётся отдельной функцией: она сохраняет события с их подробностями.
Сравнение истории учитывает смену статусов, включая HTTP 200 → 403 при одинаковом
индексе 100/100. Изменения задержки и адресов DNS не считаются изменениями статуса.

Trust Score необязателен и хранится отдельно: он не влияет на индекс obman.
Результаты Net.Coffee сохраняются в той же локальной базе, но не входят в экспорт журнала событий.
При повторной диагностике таблица показывает только текущий запуск; предыдущие запуски остаются в базе.

## Важно

Индекс `0–100` — это **только сетевой индекс obman**. Он не является оценкой риска блокировки, не отражает внутреннюю оценку Anthropic и не гарантирует работу аккаунта. Ответ HTTP показывает, что соединение установлено; он не подтверждает право доступа к сервису или аккаунту.

Даже HTTP 403, 429 и 503 подтверждают получение HTTP-ответа, поэтому могут дать
100/100 соединения. В таблице такие ответы отмечены «ВНИМАНИЕ» с пояснением.
Отказ прокси на CONNECT не считается ответом Claude. Доступность веб-страницы
не проверяет работу модели, подписки или конкретного аккаунта.

Приложение не редактирует конфигурации VPN, не меняет IP/отпечаток браузера и не пытается обходить ограничения. Проверка процессов не доказывает, какой сетевой маршрут использует конкретное приложение.

## Запуск на Windows 11

1. Установите Python 3.11+ с сайта https://www.python.org/downloads/windows/ (при установке отметьте `Add python.exe to PATH`).
2. Распакуйте архив в удобную папку.
3. Откройте PowerShell в папке `obman`.
4. Выполните:

```powershell
python obman.py
```

Зависимости устанавливать не нужно.

## Проверка из терминала Claude Code

В том же терминале (или WSL), где запускается Claude Code, из папки проекта:

```powershell
python network_diagnostics.py
python network_diagnostics.py --check-network --output report.json
```

Первая команда только показывает наличие переменных и настроек прокси текущего
Python-процесса. Вторая дополнительно делает два HTTPS GET — к `claude.ai` и
`api.anthropic.com`, без API-ключей и авторизации. Файл создаётся только если ещё
не существует. Код возврата 1 означает ошибку соединения либо HTTP-ответ вне 2xx;
это не диагноз блокировки аккаунта. Корневой URL API может штатно возвращать 404.
CLI не вызывает модель, не запускает команды Claude и не читает хранилище токенов.

Настройки Python, Node/Claude Code, браузера и Desktop могут отличаться даже в
одном терминале. Эти результаты не доказывают маршрут VPN и не проверяют
региональную доступность. Сетевые ошибки сохраняются без исходных строк исключений,
которые могут содержать адрес или пароль прокси. Отчёт не содержит значений
переменных, однако перед передачей любых файлов их стоит просмотреть.

## Где хранятся данные

SQLite-база создаётся в `%APPDATA%\\obman\\obman.db`. Журнал остаётся на компьютере; приложение само по себе никуда его не отправляет.

## Ограничения тестирования

Проверки логики и SQLite без сетевых обращений:

```powershell
python -m unittest discover -s tests -v
```

На Windows проверьте запуск окна, открытие Net.Coffee, сохранение двух результатов,
отображение изменения IP/региона и сохранность истории после перезапуска.
Также проверьте выбор запуска во вкладке истории, просмотр отчёта и соответствие
сохранённого JSON тексту в окне просмотра.

Эта версия написана для Windows 11, но среда сборки не является Windows-машиной. Перед повседневным использованием проверьте её на целевой системе.
